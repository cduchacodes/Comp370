## 4.
A well organized README can be better to understand the code because it makes it very easy for a new user to follow the code one step at a time. Because the code is modular, if a user wants to make a change, it's easy for them to know where to add their change as well as test their change by running that cell. A README has all the information in the same place while a Jupyter notebook has the information right next to the code it talks about. This makes it much easier to understand what the code does and what the information the author is trying to say.
